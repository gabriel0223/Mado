# Mado 窓

A little window into each other's screen: peer-to-peer screen sharing for two people, in the browser.

**Open it:** https://gabriel0223.github.io/mado/

1. Both people open the link (Chrome or Edge on a computer; any modern browser on a phone).
2. Type the same room name and press **Join room**.
3. On a computer, press **Share my screen**. Phones can watch and use voice chat, but phone browsers can't share their screen.

Tips for games:
- Share the game **window** with window audio turned on, so Discord voice doesn't get sent back to your partner.
- Run games borderless or windowed (exclusive fullscreen often shares as a black screen).
- If it lags, open **Stats** to see why.

Connections are direct between the two browsers (WebRTC). The free PeerJS server is only used to help the browsers find each other.
